# Сверка с первоначальным планом и оставшаяся работа

## Статус требований

| Первоначальное требование | Статус | Комментарий |
| --- | --- | --- |
| Читать MIDI и рисовать ноты | Частично | Произвольный MIDI подготавливается на Mac в `.pianoscore`; Android показывает готовые SVG-ноты. Автоматическая транскрипция прямо на планшете не реализована. |
| Страницы, ручное и автоматическое листание | Готово | Ручные кнопки, авто-переход по курсору и при обучении. |
| Масштаб нот | Готово | Pinch zoom в просмотрщике SVG. |
| Bluetooth MIDI | Готово | BLE MIDI и проверка с Roland FP-30. |
| MIDI по USB | Готово | Системные USB MIDI endpoints. |
| Проигрывание MIDI | Готово для FP-30 | Отправка в подключённое устройство, курсор и подсветка. |
| Ожидающее обучение: всё произведение | Готово | Обе/левая/правая рука. |
| Ожидающее обучение: выбранный сегмент | Готово | Интерактивные границы `От`/`До`. |
| Непрерывное обучение во время Play: всё произведение | Не готово | Нужна оценка входящих нажатий против MIDI-текущей позиции. |
| Непрерывное обучение во время Play: сегмент | Не готово | Реализуется вместе с предыдущим пунктом; Play уже поддерживает сегмент. |
| Загрузка на планшет без Play Store | Готово | Debug APK через ADB. |

## Приоритетный следующий этап

### 1. Непрерывная оценка во время Play

Цель: во время Play не ждать пользователя, но по входящему MIDI показывать правильные и неправильные ноты на текущем аккорде/моменте.

- Ввести режим `Слушать`/`Оценивать` рядом с Play.
- Для каждой ожидаемой группы определить окно допуска по времени (начать с ±200–300 мс, вынести в настройку позже).
- Сопоставлять входящие Note On с активной MIDI-группой, а не только по высоте во всём такте.
- Отображать правильные ноты зелёным, ошибки красным в текущей позиции; учитывать аккорды и удержание клавиш.
- Показать ненавязчивую статистику: правильные/ошибочные/пропущенные ноты и процент.
- Проверить отдельно BLE и USB: для BLE окно допуска, вероятно, должно быть шире.

### 2. Точная музыкальная привязка и гравировка

Это главный технический риск.

- Заполнить `scoreNoteIds` в `mapping.json` реальными `xml:id` MusicXML/MEI или SVG-IDs.
- Уйти от эвристики «ближайшая нота той же высоты» к точному событию/ноте.
- Сохранить many-to-many mapping: MIDI-нота ↔ несколько связанных нот, аккорд ↔ несколько MIDI events.
- Поддержать изменение размера такта и tempo map в расчётах выбора диапазона/курсора.
- Прогнать на нескольких произведениях с акцидентами, лига́ми, паузами, несколькими голосами и разными ключами.

### 3. Надёжность и UX

- Показать устойчивый индикатор подключения и reconnect при засыпании FP-30/BLE.
- Развести действия `Стоп`, `Сбросить обучение`, `Сбросить диапазон` и дать понятные подсказки режима выбора `От/До`.
- Добавить настройку окна аккорда (сейчас 250 мс) и окна допуска в непрерывном режиме.
- Улучшить диапазон: визуальные ручки начала/конца, точное включение последней ноты, сохранение избранных сегментов с именами.
- Запоминать последнюю композицию, масштаб, страницу, режим рук и интервал.
- Продумать небольшой onboarding для BLE/USB FP-30.

### 4. Воспроизведение и звук

- Восстанавливать program/control state перед Play из середины композиции.
- Добавить управление темпом, паузу/продолжение, loop выбранного диапазона и метроном.
- При необходимости добавить программный synth как fallback, но для обучения приоритет — локальный звук FP-30 с минимальной задержкой.

### 5. Качество проекта

- Добавить unit tests: MIDI parser, tempo map, границы диапазона, WaitingPractice, mapping validation.
- Добавить instrumented/UI tests для import, MIDI screen и диапазона.
- Настроить release signing для локальной установки, если debug APK перестанет быть удобен.
- Добавить CI build + lint и версионируемый changelog.

## Не делать до закрытия этапов 1–2

- Самостоятельный Android MIDI→MusicXML/гравировку: это отдельный большой продукт с низкой предсказуемостью качества.
- Bluetooth audio: он добавляет задержку и не нужен при использовании встроенного звука FP-30.
- Публикацию в Play Store: пользователь явно выбрал локальную установку.
