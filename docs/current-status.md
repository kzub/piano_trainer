# Piano Trainer — текущее состояние MVP

Обновлено: 2026-08-19.

## Назначение

Piano Trainer — локальный Android-тренажёр для планшета Samsung SM-X230 (Android 16 / One UI 8.5) и цифрового пианино Roland FP-30. Приложение рассчитано на установку по USB/ADB без публикации в Google Play.

Контент готовится на Mac: MIDI импортируется и проверяется в MuseScore, затем упаковывается вместе с MusicXML, SVG-страницами и учебным mapping в `.pianoscore`. Это сознательное ограничение MVP: Standard MIDI File не содержит надёжной готовой нотной гравировки.

## Реализовано

### Библиотека и партитуры

- Импорт `.pianoscore` через системный выбор файла Android; SHA-256 обязательных вложений проверяется при импорте.
- Локальная библиотека импортированных произведений.
- Удаление произведения из библиотеки с подтверждением. Исходный файл на Mac не затрагивается.
- Отображение подготовленных SVG-страниц в WebView.
- Ручное листание страниц кнопками «Назад»/«Далее».
- Автоматический переход на нужную страницу при обучении и проигрывании.
- Масштабирование партитуры стандартным жестом zoom внутри WebView.
- SVG целиком вписывается по ширине и высоте в область над нижней панелью; safe insets для обычного режима и immersive full screen для текущего режима.
- Для старых пакетов приложение удаляет нижний колонтитул Verovio и синхронно обрезает внешний и внутренний `viewBox`, не меняя координаты курсора и нот.
- Новые SVG-страницы генерируются с профилем `3360×1720`, без нижнего колонтитула; итоговая высота всех страниц нормализуется по самой высокой странице. Для проверочного пакета получился единый размер `3360×1700`.

### MIDI и Roland FP-30

- Экран MIDI-настроек.
- Bluetooth LE MIDI scan и подключение через Android MIDI API.
- Подключение системных USB MIDI-устройств.
- Полный разбор входящих MIDI-пакетов: несколько Note On/Off в одном callback,
  running status и CC64. Это не теряет Note Off и не оставляет клавиши ложноподжатыми.
- Отправка MIDI в подключённое устройство; MIDI-файл звучит средствами FP-30.
- Реальные BLE-подключение и нажатия клавиш на FP-30 проверены пользователем.

### Проигрывание

- Воспроизведение Standard MIDI File (format 0/1, PPQ; SMPTE пока не поддержан).
- Остановка отправляет All Notes Off на всех каналах.
- Визуальный курсор, переход страниц и подсветка текущих MIDI-нот во время Play.
- Play ограничивается выбранным диапазоном, если он задан.
- Выбор скорости Play: 0,25×, 0,5×, 0,75×, 1×, 1,25× и 1,5×; скорость MIDI,
  курсора и подсветки меняется синхронно.

### Ожидающее обучение

- Режим «Учить»: приложение ожидает корректные ноты и затем переходит к следующей учебной группе/аккорду.
- Корректные и ошибочные нажатия отображаются у текущего курсора.
- Повторяющиеся ноты одной высоты внутри такта различаются по порядковому номеру, поэтому курсор не перескакивает на более позднее повторение.
- Нажатия аккорда собираются в окно 250 мс; ошибочные маркеры не исчезают, пока клавиша удерживается.
- Подсказка отображает `Do Re Mi Fa Sol La Si` с октавой.
- Статус басового/скрипичного ключа и прогресс показаны компактно в центре нижней панели между кнопками «Назад»/«Далее», не отнимая высоту над партитурой.
- Выбор режима обучения: обе руки, левая рука или правая рука. Невыбранная рука не блокирует переход.
- Для `timeline-only` mapping устойчиво одноручный MIDI-трек целиком относится к своей руке: мелодия правой руки не пропускается при кратком переходе ниже C4.
- Ограничение обучения выбранным диапазоном.
- После последней учебной группы автоматически начинается новый круг выбранного
  произведения/сегмента; кнопка «Заново» не требуется.
- После окна аккорда 250 мс ошибочные маркеры сохраняются только у фактически
  удерживаемых клавиш. Отпущенные ошибки очищаются и не накапливаются.

### Интервал произведения

- Компактные кнопки `От`, `До`, `Сброс` в верхней панели.
- `От`/`До` работают как переключатели: повторное нажатие отменяет выбор точки.
- При активной кнопке можно листать страницы; касание нотного стана выбирает ближайшее MIDI-событие.
- Выбранный диапазон закрашивается бледно-серым на партитуре.
- Один диапазон применяется и к обучению, и к Play.

### Поведение приложения

- Ландшафтная ориентация.
- Экран остаётся включённым, пока Activity приложения на переднем плане.
- Полноэкранный immersive режим включён по умолчанию. Системные панели временно показываются свайпом от края и снова скрываются при получении фокуса.
- Номер каждой debug-сборки показывается в шапке как `v0.1.0-<epoch-seconds>`.
- Debug-сборка пишет выбранные `noteId/measureId/staffId` в Logcat с тегом `PianoTrainerVisual` для разбора ошибочной подсветки.

## Важные ограничения MVP

- Приложение импортирует подготовленный `.pianoscore`, а не произвольный `.mid` напрямую. Mac-пайплайн нужен для читаемой нотной записи.
- В новых пакетах `schemaVersion: 2` привязка MIDI→MusicXML→SVG точная: `mapping.json`
  содержит `scoreNoteIds`, а SVG хранит те же ID в `data-id`. Один MIDI event может
  ссылаться на несколько связанных нот (ties). Старые schemaVersion 1 пакеты остаются
  импортируемыми, но для них используется запасная эвристика.
- Автоматическое определение рук исправляет переход мелодии через C4 для треков, где не менее 90% нот относятся к одной руке. Действительно смешанные MIDI-треки требуют проверенной понотной разметки `hand` на Mac.
- Граница диапазона в новом пакете выбирается по точному `scoreNoteId`; визуальное
  серое выделение внутри такта остаётся пропорциональным временем и потому приблизительно.
- Play с середины произведения пока не восстанавливает полный исторический набор MIDI controller/program events до начала диапазона. Для FP-30 с фортепианским тембром это приемлемо, но для сложных аранжировок нужен pre-roll состояния.
- Скорость выбирается перед запуском Play; смена скорости во время уже идущего
  воспроизведения пока намеренно отключена.
- Воспроизведение использует звук Roland FP-30. Встроенный программный синтезатор и вывод в Bluetooth-наушники не реализованы.
- Play одновременно работает как непрерывный режим оценки: внешние Note On сравниваются с текущей группой без остановки воспроизведения. Правильные ноты отмечаются зелёным, ошибки — красным, а по окончании показан итог правильных и пропущенных групп. Окно допуска сейчас равно половине четверти (для исходного файла примерно ±312 мс); его нужно откалибровать на FP-30 по BLE и USB.

## Проверка на устройстве

Базовый smoke test после сборки:

1. Подключить планшет по USB с включённой USB debugging и проверить `adb devices -l`.
2. Установить APK командой `adb install -r`.
3. Открыть композицию, убедиться, что отображается номер новой сборки.
4. В MIDI-настройках подключить FP-30 по BLE или USB и проверить Note On/Off.
5. Проверить Play на всём произведении и на выбранном диапазоне, сыграть несколько правильных и неправильных нот на FP-30 и сверить итог оценки.
6. Проверить «Учить» для обеих, левой и правой руки; сыграть корректную ноту, неверную ноту и аккорд.
7. Выбрать `От`, перелистнуть страницу, выбрать ноту; затем аналогично `До`; проверить серое выделение и `Сброс`.
