# Review реализации Piano Trainer — 2026-08-19

## Итог

Собран работающий локальный Android-тренажёр для Samsung SM-X230 и Roland FP-30.
Приложение устанавливается по ADB, импортирует подготовленные `.pianoscore`, показывает
постраничную нотацию, подключается к FP-30 по BLE MIDI/USB, проигрывает MIDI через
пианино и поддерживает обучение обеих/одной рукой, диапазоны и оценку во время Play.

Ключевое архитектурное улучшение этого этапа — отказ от выбора ноты по высоте и
примерной X-координате. Каждый MIDI Note On в новом пакете связан с устойчивыми
идентификаторами MusicXML и SVG. Это устраняет пропуски повторяющихся нот, смешение
голосов и скачки курсора при повторном перелистывании или масштабировании.

## Что сделано

- Native Kotlin/Compose UI, полноэкранный режим, удержание экрана включённым,
  автоматический номер debug-сборки в интерфейсе.
- Библиотека `.pianoscore`: импорт, SHA-256 проверка, удаление, готовые SVG-страницы,
  ручное и автоматическое листание, pinch zoom.
- BLE MIDI и USB MIDI; FP-30 реально проверен пользователем. MIDI-файл отправляется в
  FP-30, поэтому живые клавиши используют его встроенный звук без задержки планшетного
  синтезатора.
- Play: диапазон, курсор/активные ноты, непрерывная оценка, скорости 0,25×–1,5×.
- Ожидающее обучение: аккорды, окно 250 мс, Do/Re/Mi с октавами, левая/правая/обе руки,
  автоповтор всего произведения или выбранного отрезка.
- Диапазоны `От`/`До`/`Сброс` выбираются нажатием на точную нотную позицию и одинаково
  действуют на Play и обучение.
- Mac pipeline: MusicXML получает стабильные `xml:id`/`id`; Verovio экспортирует их в
  SVG `data-id`; mapping содержит many-to-many `scoreNoteIds`, такты и длительности.
  Сборка останавливается при неполном соответствии MIDI и MusicXML.
- Для `Listen to Your Heart`: 918/918 MIDI-событий связаны с 1 453 напечатанными
  головками с учётом ties; пакет прошёл строгий audit и содержит 3 широкие страницы
  `3360×1700` без footer Verovio.

## Исправленные дефекты

| Симптом | Причина | Исправление |
| --- | --- | --- |
| Пустые/обрезанные страницы и footer Verovio | Несовпадение внешнего и внутреннего SVG `viewBox` | Синхронный crop обоих viewBox, профиль 3360×1720, нормализация страниц |
| Курсор перепрыгивал на повторяющуюся ноту | Выбор по высоте/X и предположение 4/4 | Точные SVG ID, map тактов, защита от stale WebView/Play callback |
| В правой руке пропадали ноты ниже C4 | Наивное разбиение только по высоте | Устойчивое присвоение сильно доминирующих MIDI-источников рукам |
| Дубликат Note On двигал обучение дальше | Сообщение повторно принималось при удержании | Set удерживаемых клавиш и идемпотентная обработка |
| Неверные маркеры росли бесконечно | Набор попытки ждал отпускания всех когда-либо нажатых клавиш | По окончании окна остаются только реально удерживаемые ноты |
| Маркеры оставались при отпущенных клавишах | Приёмник MIDI читал только первые 3 байта callback | Декодируется весь пакет, включая несколько сообщений и running status |
| Play подсвечивал будущую группу, а курсор — текущую | Оценка использовалась как источник визуального курсора | Курсор всегда берёт текущую точную MIDI-группу |

## Проверки

- `./gradlew :app:testDebugUnitTest :app:assembleDebug` — успешно.
- Есть unit tests для присвоения рук, повторных нот, циклического обучения, очистки
  ошибочных маркеров и декодирования batch MIDI/running status.
- `audit_score_package.py --strict` — успешно для нового пакета.
- APK и новый пакет импортированы на SM-X230 через ADB; визуально проверены портретный
  и альбомный режимы, курсор, exact SVG ID и отсутствие нижнего footer.
- Последняя установленная проверенная сборка: `v0.1.0-1787170049`.

## Оставшиеся риски

- Реальное длительное тестирование FP-30 по BLE и USB после исправления batch MIDI:
  последовательности с педалью, аккордами и быстрыми Note On/Off.
- Контент по-прежнему готовится на Mac: автоматическая качественная транскрипция
  произвольного MIDI прямо на планшете не является частью MVP.
- Нужны обработка reconnect после сна BLE, восстановление MIDI controller/program state
  при старте Play из середины, пауза/продолжение и сохранение пользовательских настроек.
- Нужны instrumented/UI tests и CI; сейчас проверка UI в основном ручная на устройстве.
