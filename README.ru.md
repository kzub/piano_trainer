# Piano Trainer

**English version: [README.md](README.md)**

Piano Trainer — локальное Android-приложение для занятий на цифровом пианино. Оно показывает партитуру из MuseScore, принимает MIDI с клавиатуры, позволяет разучивать одну или обе руки и воспроизводит произведение.

Проект проверялся на Samsung SM-X230 и Roland FP-30, но использует стандартные Android MIDI API и может работать с другими совместимыми устройствами.

## Возможности

- Импорт проверенных пакетов `.pianoscore` в локальную библиотеку.
- Оригинальная гравировка MuseScore в масштабируемых SVG-страницах.
- USB MIDI и Bluetooth LE MIDI-клавиатуры.
- Воспроизведение учебного MIDI через подключённое пианино.
- Режим **Practise**: ожидание правильных нот и индикация ошибок.
- Левая, правая или обе руки, выбор скорости и диапазона тактов.

## Быстрый старт

### 1. Установите приложение

1. Откройте [`android-app`](android-app) в Android Studio.
2. Установите Android SDK Platform 37 и Build Tools 36.0.0.
3. Соберите debug APK:

   ```sh
   cd android-app
   ./gradlew :app:assembleDebug
   ```

4. Установите `app/build/outputs/apk/debug/app-debug.apk` на планшет с Android 12 или новее — через Android Studio или командой:

   ```sh
   adb install -r app/build/outputs/apk/debug/app-debug.apk
   ```

Приложение работает в ландшафтной ориентации и запускается во весь экран.

### 2. Скачайте партитуру с MuseScore.com

Скачивайте только собственные произведения, материалы из общественного достояния или партитуры, на которые у вас есть разрешение. Учитывайте лицензию на странице партитуры и условия MuseScore. Кнопка загрузки может требовать подписку; не пользуйтесь сторонними загрузчиками и не обходите ограничения доступа.

1. На [MuseScore.com](https://musescore.com/) найдите партитуру **Solo Piano** с верхним и нижним нотным станом.
2. Откройте её, проверьте лицензию и инструменты в разделе **Score info**.
3. Нажмите **Download** и, если доступно, выберите исходный файл **MuseScore** (`.mscz`). Сохраните его на Mac, например в `~/Downloads`.
4. Откройте `.mscz` в MuseScore Studio. Убедитесь, что в нём ровно одна фортепианная партия с двумя играемыми руками; при необходимости поправьте ноты и сохраните файл.

Для нового конвейера нужен именно `.mscz`. PDF — это изображение, а MIDI не гарантирует читаемую нотную гравировку, поэтому эти форматы не поддерживаются как входные.

### 3. Конвертируйте файл

Установите [MuseScore Studio 4](https://musescore.org/ru/download), добавьте `mscore` в `PATH` и установите Python 3.10+.

Выполните из корня репозитория:

```sh
mscore --version
python3 --version

python3 score-preparer/src/prepare_mscz.py \
  /absolute/path/to/your-score.mscz \
  --output local-content/your-score.pianoscore

python3 score-preparer/src/audit_score_package.py \
  local-content/your-score.pianoscore --strict
```

Конвертер получает SVG и MusicXML из MuseScore, строит чистый MIDI двух рук, связывает ноты с их позицией на странице и записывает SHA-256. При небезопасном определении рук или связи с гравировкой он остановится с ошибкой, а не создаст непроверенный пакет.

### 4. Загрузите пакет и занимайтесь

**Через приложение**

1. Скопируйте `your-score.pianoscore` на планшет, например в **Downloads**.
2. Откройте Piano Trainer и нажмите **Import score**.
3. Выберите пакет в системном проводнике, а затем нажмите **Open** в библиотеке.

**Напрямую с Mac разработчика**

Если подключён один планшет с включённой USB debugging:

```sh
python3 score-preparer/src/install_pianoscore.py \
  local-content/your-score.pianoscore
```

При нескольких устройствах добавьте `--serial <adb-serial>`. Скрипт проверит пакет, скопирует его в закрытую библиотеку приложения и перезапустит Piano Trainer.

В приложении откройте **MIDI**: подключите клавиатуру по USB либо разрешите «Устройства поблизости» и нажмите **Scan Bluetooth MIDI**. Откройте произведение, выберите руку и скорость:

- **Practise** — курсор ждёт правильную ноту или аккорд;
- **Play** — ноты звучат на подключённом инструменте, а курсор движется по партитуре;
- чтобы разучивать или проигрывать фрагмент, двигайте курсор кнопками **←** и **→** внизу
  экрана, нажмите **[** на такте начала фрагмента, дойдите до такта конца и нажмите **]**.
  Нажатие обеих кнопок на одном такте выделяет ровно этот такт, **Сброс** снимает выделение.
  И обучение, и Play идут по выбранному фрагменту по кругу.

## Те же операции с агентом

Агент полезен для локальных шагов подготовки; он не встроен в Android-приложение. Передайте ему локально сохранённый `.mscz`, полученный законно, и подключённый планшет. Не просите агента обходить ограничения MuseScore или авторские права.

Пример задания:

> В репозитории Piano Trainer подготовь `/absolute/path/to/my-score.mscz` для приложения. Проверь доступность `mscore` и Python, создай `local-content/my-score.pianoscore`, запусти строгую проверку и сообщи, что нужно исправить в MuseScore, если возникнет ошибка. Если подключён ровно один разрешённый ADB-планшет, установи проверенный пакет. Не скачивай партитуры, не используй сторонние загрузчики и не обходи требования лицензии или подписки.

Агент должен запросить решение пользователя, если права на произведение неясны, исходный файл недоступен, требуется исправление в MuseScore или нужен доступ к подключённому устройству.

## Ограничения

- Приложение импортирует `.pianoscore`, а не произвольные `.mid`, `.pdf` или `.musicxml`.
- Для нового пакета нужна одна фортепианная партия из двух станов и события обучения для обеих рук.
- Воспроизведение отправляется на подключённый инструмент; программного синтезатора в приложении нет.
- Проект рассчитан на локальную установку по USB/ADB, а не на Google Play.
