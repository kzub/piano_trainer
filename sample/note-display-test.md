# Проверка нот в двух ключах

[`note-display-test.musicxml`](note-display-test.musicxml) содержит по одному такту
для каждой пары «буква + альтерация»: C, D, E, F, G, A, B × обычная, бемоль,
диез. В каждом из тактов 1–21 одна нота записана в скрипичном ключе в четвёртой
октаве и такая же по названию в басовом ключе в третьей октаве. Альтерация
указана явно в обоих станах.

| Такты | Ноты скрипичного стана | Ноты басового стана |
| --- | --- | --- |
| 1–3 | C4, C♭4, C♯4 | C3, C♭3, C♯3 |
| 4–6 | D4, D♭4, D♯4 | D3, D♭3, D♯3 |
| 7–9 | E4, E♭4, E♯4 | E3, E♭3, E♯3 |
| 10–12 | F4, F♭4, F♯4 | F3, F♭3, F♯3 |
| 13–15 | G4, G♭4, G♯4 | G3, G♭3, G♯3 |
| 16–18 | A4, A♭4, A♯4 | A3, A♭3, A♯3 |
| 19–21 | B4, B♭4, B♯4 | B3, B♭3, B♯3 |
| 22 | C4 | C4 |
| 23 | C5 | C4 |

Такты 22–23 проверяют, что одинаковое имя ноты не подменяет реальную высоту
и место на стане. В такте 22 MIDI 60 соответствует двум записанным C4; при
ошибочном соседнем нажатии маркер должен появиться возле обоих станов. В такте
23 MIDI 60 соответствует только басовому C4, а MIDI 72 — скрипичному C5.

Автоматическая проверка таблицы, MIDI высот, расположения и выбора стана:

```sh
node android-app/scripts/test-score-rendering.js
```
