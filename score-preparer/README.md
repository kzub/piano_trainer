# Score preparer

Основной и рекомендуемый входной формат — **MuseScore `.mscz`**. Один исходный файл
содержит отредактированную партитуру, две фортепианные руки, повторы и оформление.
Конвертер использует штатные экспорты MuseScore и создаёт проверяемый `.pianoscore`:

- SVG-страницы именно из MuseScore, без повторной вёрстки Verovio;
- планшетные страницы, нарезанные только в межсистемных зазорах: ноты и заголовки
  текущей системы сохраняются, элементы соседней системы не попадают в кадр;
- MusicXML как семантический источник нот;
- чистый учебный MIDI только из нот фортепианных станов (правая и левая руки);
- точную связь учебных позиций с графическими элементами SVG;
- SHA-256 для MIDI, MusicXML, mapping и каждой страницы.

PDF сохраняет только картинку, MIDI теряет нотную семантику, Audio непригоден для
проверки сыгранных нот. Отдельный MusicXML полезен как обменный формат, но `.mscz`
надёжнее как единственный пользовательский вход: он сохраняет и семантику, и ту
вёрстку, которую пользователь уже проверил в MuseScore.

## Требования

- Python 3.10 или новее;
- MuseScore Studio 4 с CLI-командой `mscore` в `PATH`;
- для установки на debug-планшет — Android SDK Platform Tools (`adb`).

Проверка окружения:

```sh
mscore --version
python3 --version
adb devices -l
```

## Конвертация `.mscz → .pianoscore`

Из корня репозитория выполните одну команду:

```sh
python3 score-preparer/src/prepare_mscz.py \
  /absolute/path/to/composition.mscz \
  --output local-content/composition.pianoscore
```

Команда завершается ошибкой, если MuseScore не нашёл ровно одну фортепианную партию,
если не удалось связать семантические позиции с SVG или если в учебном timeline нет
нот одной из рук. В итоговый MIDI не попадают дорожки воспроизведения аккордовых
символов и другие синтезированные MuseScore инструменты.

Независимая строгая проверка пакета:

```sh
python3 score-preparer/src/audit_score_package.py \
  local-content/composition.pianoscore --strict
```

## Прямая установка в приложение

Для установленной debug-сборки ручной импорт через `Downloads` не нужен:

```sh
python3 score-preparer/src/install_pianoscore.py \
  local-content/composition.pianoscore --serial <adb-serial>
```

Скрипт до копирования проверяет manifest и все контрольные суммы, помещает пакет в
`files/scores` приложения через `run-as`, проверяет наличие файла и перезапускает
Piano Trainer. Если подключено ровно одно устройство, `--serial` можно не указывать.

## Что проверять на устройстве

После установки:

1. композиция появилась в библиотеке и открывается без ошибки;
2. видны скрипичный и басовый станы;
3. перелистывание охватывает всю партитуру;
4. запуск воспроизведения перемещает курсор и подсвечивает ноты MuseScore;
5. режим обучения содержит события обеих рук.

Для автоматизированной диагностики используйте `adb shell uiautomator dump`, снимок
экрана и сообщения `PianoTrainerVisual` из logcat.

## Старый процесс

Скрипты `generate_timeline_mapping.py`, `render_pages.py` и `prepare_score.py`
оставлены для совместимости с уже подготовленными MIDI/MusicXML пакетами schema 1–2.
Для новых композиций их использовать не следует: независимые MIDI и MusicXML могут
расходиться после импорта, а повторный рендер меняет проверенную в MuseScore вёрстку.
